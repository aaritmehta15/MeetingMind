# Demo Transcripts Dataset

This directory contains synthetic and pop-culture meeting transcripts used exclusively for testing, demonstrating, and evaluating the **MeetingMind Intelligence Engine**.

## 🛡️ Data Authenticity & Privacy Guarantee

All transcripts in this folder are **100% synthetic or fictional**. We guarantee that:
- **No Real Corporate Data**: These files do not contain real proprietary, corporate, or internal business discussions.
- **Zero PII**: There is no Personally Identifiable Information (PII) present in these transcripts.
- **Fictional Context**: Scenarios like `dunder-mifflin-sales.txt` (The Office) and `mad-men-heinz.txt` (Mad Men) are derived from public pop-culture television scripts for the purpose of entertaining, relatable demonstrations.
- **Synthetic Generation**: Scenarios like `q1-planning-sarah.txt` were artificially generated by LLMs specifically to test the Extraction Studio's capacity to handle action items, deadlines, and ownership assignment.

## 🎯 Purpose

These files are provided so that developers and users can immediately test the extraction, chunking, and RAG capabilities of the platform without needing to upload their own sensitive meeting transcripts. They are explicitly formatted to challenge the NLP engine with multi-speaker diarization and ambiguous action-item phrasing.
